# 직원 정보 관리 시스템 — 입사부터 퇴사까지 한곳에서

> GSD 48기 (2026-08-23) · 기획자의 첫 배포 프로젝트
> **https://employee-directory-sigma-henna.vercel.app**

## 문제

- 140명 회사의 직원 정보 = 엑셀 인사기록카드 1파일, 186컬럼
- 한 명 정보 확인에 좌우 스크롤 노동 · 누가 언제 바꿨는지 이력 없음
- 퇴사인데 퇴사일 공란 같은 정합성 사고 · 인원 집계는 매번 수작업

## 해결 — 핵심 3가지

1. **모든 변경은 자동으로 이력이 된다** — 입사·부서이동·휴직·퇴사가 발령이력에 자동 기록 (DB 트리거 — 화면을 우회해도 남는다)
2. **시스템이 정합성을 강제한다** — 퇴사일 없는 퇴사 저장 차단 · 삭제 자체가 불가 (상태 변경만 존재)
3. **집계 0초** — 현원 141 · 재직/휴직/퇴사예정/퇴사 · 인원 변동 · 부서별 인원이 대시보드에 자동 표시

## 데이터

- 실제 회사 규모(140명)를 그대로 반영한 더미 158명 · 발령이력 250건
- 민감정보(주민번호·병역 등)는 컬럼 자체를 설계에서 제외

## 스택

- Claude Code로 기획·제작·배포 전 과정 진행 (기획 세션 + 제작 세션 분업)
- Next.js · Supabase (DB·트리거·RLS) · Vercel

## 만들면서 배운 것

- 기획자의 요구사항 정의(R1~R16)가 그대로 구현·검증 체크리스트가 된다
- 30년차 HR 전문가 패널 시뮬레이션으로 요구사항을 2차 검증 — "부서는 텍스트가 아니라 마스터다"
